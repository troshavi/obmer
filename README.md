# Обмер — план помещения по измерениям

**Обмер** — бесплатный браузерный инструмент, который помогает построить план помещения по реальным замерам стен и диагоналей. Нарисуйте приблизительную схему, укажите измеренные расстояния — приложение рассчитает согласованную геометрию, в том числе углы между стенами, с учётом погрешностей замеров.

**Для чего нужен:** когда размеры помещения измерены рулеткой или лазерным дальномером, но углы неизвестны, а измерения немного противоречат друг другу. Вместо ручного подбора координат можно задать известные расстояния и геометрические связи, выполнить уравнивание и экспортировать результат в AutoCAD.

**[Открыть Обмер](https://troshavi.github.io/obmer/)** · **[Сообщить о проблеме](https://github.com/troshavi/obmer/issues)**

Приложение работает локально в браузере: без регистрации, сервера и отправки чертежей в облако. При необходимости файл `index.html` можно сохранить и открывать без интернета.

> **Статус:** экспериментальный инженерный инструмент. Уравнивание не заменяет контрольные замеры; результат следует проверять, особенно при противоречивых или недостаточных данных.

## Быстрый старт

1. **[Откройте Обмер](https://troshavi.github.io/obmer/)** или скачайте [`index.html`](index.html) и откройте локально.
2. Нарисуйте примерный контур помещения линиями.
3. Введите измеренные длины стен и диагоналей, при необходимости задайте точность замеров и геометрические привязки.
4. Запустите **«Уравнять МНК»** и проверьте невязки.
5. Экспортируйте согласованный план в **DXF** для AutoCAD или сохраните редактируемый проект в **JSON**.

## Возможности

- Создание и редактирование отрезков, общие вершины и привязка концов через контекстные действия.
- Ввод измеренных длин в миллиметрах и индивидуальных значений **σ** (оценка точности замера).
- **σ = 0** — жёстко заданный эталонный размер; **σ > 0** — измерение с весом, зависящим от σ.
- Геометрические ограничения: горизонтальность, вертикальность, параллельность, перпендикулярность, коллинеарность и точка на линии.
- Уравнивание МНК с диагностикой несовместимых жёстких ограничений.
- Отображение невязок и перенос текущих невязок в σ (с сохранением меньших ранее установленных значений).
- Отмена действий: **Ctrl+Z** (Windows/Linux) или **⌘Z** (macOS).
- Линейка, масштабирование и вписывание чертежа в окно.
- Сохранение/открытие проекта в JSON, экспорт SVG и экспорт уравненной геометрии в **DXF** для AutoCAD.

## Как пользоваться

1. Нажмите **«Линия»** и нарисуйте схему. При создании линий используйте существующие вершины для общих узлов.
2. Выделите линию и введите её **измеренную длину** и **σ** в правой панели.
3. Выделяйте линии и точки, чтобы добавлять геометрические привязки через раздел **«Доступные привязки для выделения»**.
4. Нажмите **«Уравнять МНК»**, затем проверьте сообщения и **невязки измерений**.
5. Сохраните проект в **JSON** для продолжения работы; используйте **DXF** для переноса линий в CAD.

### Что означает σ?

σ — оценка стандартной погрешности измерения в миллиметрах, **не** фактическая невязка. Чем меньше положительное σ, тем сильнее размер влияет на уравнивание. **σ = 0** означает строгое ограничение; пустое значение означает, что индивидуальная σ ещё не задана (используется общая настройка).

Кнопка **«Зафиксировать невязки в σ»** записывает модуль текущей невязки, если индивидуальная σ не задана или больше невязки. Уже установленный эталон и меньшая σ сохраняются. Это **не** заменяет оценку точности измерений метрологическим методом.

## Экспорт

| Формат | Назначение |
| --- | --- |
| **JSON** | Редактируемый проект: точки, линии, размеры, привязки и вид |
| **SVG** | Векторное представление текущего чертежа |
| **DXF (AutoCAD)** | Отрезки уравненной геометрии на слое `ADJUSTED`, единицы — мм, масштаб 1:1; ASCII DXF R12 |

В DXF попадают геометрические отрезки без размерных надписей и вспомогательного интерфейса. Если отдельный жёлтый слой доступен, используются его координаты; иначе экспортируется текущая геометрия, в которую записывается результат уравнивания. Координаты Y преобразуются в CAD-направление вверх.

## Горячие клавиши

| Комбинация | Действие |
| --- | --- |
| `Ctrl+Z` / `⌘Z` | Отменить последнее изменение |
| `Delete` / `Backspace` | Удалить выбранную привязку; при повторном нажатии — выбранные объекты |
| `Shift` + щелчок | Выделить несколько объектов |
| `Esc` | Вернуться в режим выделения |

## Ограничения

- Для получения однозначного плана необходимо достаточное количество независимых измерений и геометрических связей.
- При противоречивых или плохо обусловленных данных расчёт может не сойтись. Проверяйте невязки и исходные замеры.
- Проект сохраняется в JSON вручную; история отмены не переносится между сеансами.
