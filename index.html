Уравнивание
Справка

Ручной эскиз — только начальное приближение. После ввода размеров координаты линий заменяются рассчитанными по МНК. При противоречивых измерениях показывается предупреждение. Длины в мм, σ влияет на вес замера.

Нарисуй линии, свяжи концы и введи измеренные длины.

Переносит модуль текущей невязки каждой измеренной линии в её σ. Если заданное σ уже меньше невязки, оно сохраняется. Пустое поле σ означает использование значения по умолчанию при МНК. Нулевая невязка устанавливает σ = 0 (эталон). Уже установленный эталон сохраняется.
